Modern Command Bar – Custom Buttons with Power Fx and JavaScript

Customize model-driven app command bars with the modern command designer, covering Power Fx actions and visibility, JavaScript commands, form vs grid locations, and replacing classic Ribbon Workbench customizations.

The command bar (formerly the ribbon) holds buttons such as New, Save and Deactivate. The modern command designer lets makers add buttons with Power Fx for both action and visibility, without the old Ribbon Workbench XML.

#Command locations

Location Context
Main form One record (Self.Selected.Item)
Main grid View of many records (Self.Selected.AllItems)
Sub-grid Related records on a form
Associated view Related records in a separate view

#Power Fx command example: "Mark as Critical"

Action (OnSelect)Power Fx
Patch(Deviations, Self.Selected.Item, { Severity: 'Severity (Deviations)'.Critical, Priority: 'Priority (Deviations)'.High });
Notify("Marked as critical", NotificationType.Warning)
VisiblePower Fx
Self.Selected.Item.Status <> 'Status (Deviations)'.Closed &&
User().Email in Concat(Filter('QA Leads', Active = true), Email & ";")

For grids, use ForAll(Self.Selected.AllItems, Patch(...)) and set visibility to CountRows(Self.Selected.AllItems) > 0.

#When to use JavaScript instead

Use a JavaScript action (web resource + function name + parameters such as PrimaryControl or SelectedControlSelectedItemIds) when you need the Client API: opening dialogs or custom pages with navigateTo, calling custom APIs, or complex UI interactions.

#Interview questions

Q1What replaced the Ribbon Workbench for most customizations?

The modern command designer in the app designer, which supports Power Fx for actions and visibility, plus JavaScript actions, all stored in solutions.

Q2How do you hide a command for closed records?

Set the command's Visible property to a Power Fx formula such as Self.Selected.Item.Status <> 'Status (Deviations)'.Closed.
