PowerApps Component Framework (PCF) – Build Code Components in TypeScript

Build a PCF code component from scratch, covering pac pcf init, manifest, init/updateView/getOutputs/destroy lifecycle, React (virtual) controls, dataset vs field components, testing in the harness, packaging in a solution and using it in canvas and model-driven apps.

PCF code components let professional developers build custom controls (TypeScript, optionally React) that makers then use like built-in controls in model-driven forms and views, canvas apps and Power Pages. Examples: a star rating, a signature pad, a colour-coded timeline, a barcode scanner or an interactive Gantt grid.

#Lifecycle

#Build a "StarRating" field component

Scaffold (Power Platform CLI)Bash
pac pcf init --namespace Contoso --name StarRating --template field --framework react --run-npm-install
npm start watch          # test harness at http://localhost:8181
ControlManifest.Input.xmlXML
<manifest>
  <control namespace="Contoso" constructor="StarRating" version="1.0.0" display-name-key="Star rating"
           description-key="Rate 1–5" control-type="virtual">
    <property name="value" display-name-key="Rating" of-type="Whole.None" usage="bound" required="true" />
    <property name="maxStars" display-name-key="Max stars" of-type="Whole.None" usage="input" default-value="5" />
    <resources>
      <code path="index.ts" order="1" />
      <platform-library name="React" version="16.14.0" />
      <platform-library name="Fluent" version="9.46.2" />
    </resources>
  </control>
</manifest>
index.ts (virtual/React control)TypeScript
import { IInputs, IOutputs } from './generated/ManifestTypes';
import * as React from 'react';
import { Stars } from './Stars';

export class StarRating implements ComponentFramework.ReactControl<IInputs, IOutputs> {
  private notify!: () => void;
  private current = 0;

  public init(context: ComponentFramework.Context<IInputs>, notifyOutputChanged: () => void): void {
    this.notify = notifyOutputChanged;
  }

  public updateView(context: ComponentFramework.Context<IInputs>): React.ReactElement {
    this.current = context.parameters.value.raw ?? 0;
    return React.createElement(Stars, {
      value: this.current,
      max: context.parameters.maxStars.raw ?? 5,
      disabled: context.mode.isControlDisabled,
      onChange: (v: number) => { this.current = v; this.notify(); }
    });
  }

  public getOutputs(): IOutputs { return { value: this.current }; }
  public destroy(): void { /* cleanup */ }
}
Stars.tsxTSX
export const Stars: React.FC<{ value: number; max: number; disabled: boolean; onChange: (v: number) => void }> =
  ({ value, max, disabled, onChange }) => (
    <div role="radiogroup" aria-label="Rating">
      {Array.from({ length: max }, (_, i) => i + 1).map(n => (
        <button key={n} role="radio" aria-checked={n === value} disabled={disabled}
                onClick={() => onChange(n)} style={{ fontSize: 22, background: 'none', border: 0, cursor: 'pointer' }}>
          {n <= value ? '★' : '☆'}
        </button>
      ))}
    </div>
  );

#Package and deploy

Add to a solution and buildBash
mkdir StarRatingSolution && cd StarRatingSolution
pac solution init --publisher-name Contoso --publisher-prefix ci
pac solution add-reference --path ..
dotnet build -c Release            # → bin/Release/StarRatingSolution.zip
# or for quick dev: pac pcf push --publisher-prefix ci

Import the solution, then:

  • Model-driven: form designer → field → Components → add Star rating.
  • Canvas: enable code components for the environment, then Insert → Get more components → Code.

#Field vs dataset components

Field component Dataset component
Binds to One column A view/table (rows)
Example Rating, signature, color picker Custom grid, Kanban, calendar
API context.parameters.x.raw context.parameters.dataset.records, paging, sorting

#Interview questions

Q1What is the difference between a standard and a virtual (React) PCF control?

A standard control renders into a DOM container you manage (init gets the container). A virtual control returns a React element from updateView, uses the platform's shared React and Fluent libraries, and results in smaller bundles and better performance.

Q2How does a PCF control tell the host its value changed?

It calls the notifyOutputChanged callback received in init. The host then calls getOutputs() to read the new values for bound properties.
