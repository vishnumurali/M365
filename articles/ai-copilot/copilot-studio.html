Copilot Studio – Building Agents with Knowledge, Topics, Actions and Autonomous Triggers

Build agents with Copilot Studio (formerly Power Virtual Agents), covering generative orchestration, knowledge sources (SharePoint, Dataverse, websites, files), topics with Power Fx, tools and actions (connectors, flows, REST), autonomous triggers, channels (Teams, M365 Copilot, web), ALM and governance.

Copilot Studio (Power Virtual Agents until 2023) is the low-code tool for building agents: conversational or autonomous assistants that use your knowledge and take actions through connectors.

#Example: Deviation helpdesk agent

#Topics (when you need deterministic logic)

Topic outline: Report a deviationText
Trigger phrases: "report a deviation", "log a deviation", "quality issue"
1. Question: Which area? (Choice: Production / Warehouse / Lab) → Topic.Area
2. Question: Describe the issue (text) → Topic.Description
3. Condition: if Topic.Description contains "temperature" → set Topic.Severity = "Major"
4. Call action: flow "Create deviation" (Area, Description, Severity, User email)
5. Message: "Created {Topic.RefNo}. QA will review within 24 hours." + link
Knowledge first, topics where precision matters

Let generative answers handle FAQ-style questions from curated knowledge, and build topics for transactions and regulated flows where wording and steps must be exact.

#Autonomous agents

Agents can be triggered by events (a new email, a Dataverse row, a schedule) and act without a chat, for example triaging incoming supplier emails into SharePoint and notifying owners. Govern them carefully: restrict tools, add approvals for impactful actions, and review activity logs.

#Interview questions

Q1What is the difference between knowledge and topics in Copilot Studio?

Knowledge sources (SharePoint, websites, Dataverse, files) let the agent generate answers from content dynamically. Topics are authored conversation paths with questions, conditions and actions for deterministic, step-by-step interactions.

Q2How does a Copilot Studio agent perform actions such as creating a SharePoint item?

Through tools/actions: Power Automate flows, connector operations, or custom connectors to REST APIs. The agent fills inputs from the conversation and runs the action with the configured authentication (user or maker credentials).
