How Microsoft 365 Copilot Works – Grounding, the Semantic Index, Permissions and Extensibility

A clear architecture of Microsoft 365 Copilot, covering the orchestrator, grounding through Microsoft Graph and the semantic index, permission-trimmed retrieval, responsible AI and data boundaries, Copilot Chat vs licensed Copilot, and the extensibility model (agents, connectors, plugins).

Microsoft 365 Copilot combines large language models with your organization's data in Microsoft 365, retrieved through Microsoft Graph and only what the user can already access. SharePoint is its largest knowledge source, so SharePoint quality and permissions directly determine Copilot quality and safety.

#Architecture

#Key facts

Topic Fact
Permissions Copilot can only use content the user can already access (no new permissions)
Training Prompts, responses and your data are not used to train foundation models
Data boundary Processing happens within the Microsoft 365 service boundary, with EU Data Boundary support
Labels Sensitivity labels and encryption are respected; outputs inherit labels where applicable
Auditing Copilot interactions are captured for Purview audit, eDiscovery and retention

#Copilot Chat vs Microsoft 365 Copilot

Microsoft 365 Copilot Chat Microsoft 365 Copilot (licensed)
Grounding Web (+ agents with org data via pay-as-you-go) Work data via Graph + web
In apps Chat experience In Word, Excel, PowerPoint, Outlook, Teams, SharePoint
Licence Included for Entra users Per-user add-on

#Extensibility

SharePoint agents

Scoped agents over sites and files.

Copilot Studio

Low-code agents with knowledge, actions and topics.

Declarative agents

Instructions + knowledge + API actions, built with the Agents Toolkit.

Graph connectors

Bring external content into the index.

#Interview questions

Q1How does Copilot avoid showing users data they shouldn't see?

It retrieves grounding data through Microsoft Graph and the semantic index as the user, so results are security-trimmed by existing permissions. That is also why oversharing in SharePoint becomes visible with Copilot: if a user technically has access, Copilot can surface it.

Q2What is the semantic index?

An index built over Microsoft 365 content (and connectors) with semantic representations that let Copilot find conceptually relevant information, not just keyword matches, while respecting permissions.
