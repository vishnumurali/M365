Every click in the Power Query editor writes M code. Reading and writing M directly (Advanced editor) unlocks transformations the UI can't do and makes queries maintainable.

#Anatomy of a query

let … in, one step per linePower Query M
let
    Source      = SharePoint.Tables("https://contoso.sharepoint.com/sites/quality", [Implementation = "2.0", ViewMode = "All"]),
    Deviations  = Source{[Title = "Deviations"]}[Items],
    Selected    = Table.SelectColumns(Deviations, {"ID", "Title", "Severity", "DueDate", "Owner", "Plant"}),
    Typed       = Table.TransformColumnTypes(Selected, {{"ID", Int64.Type}, {"Title", type text}, {"DueDate", type date}}),
    OwnerEmail  = Table.AddColumn(Typed, "OwnerEmail", each try [Owner][EMail] otherwise null, type text),
    PlantName   = Table.AddColumn(OwnerEmail, "PlantName", each [Plant][Title], type text),
    OpenOnly    = Table.SelectRows(PlantName, each [Severity] <> null and [DueDate] <> null),
    Removed     = Table.RemoveColumns(OpenOnly, {"Owner", "Plant"})
in
    Removed

#Most-used functions

Task M
Filter rows Table.SelectRows(t, each [Status] = "Open")
Add column Table.AddColumn(t, "DaysOpen", each Duration.Days(DateTime.LocalNow() - [Created]), Int64.Type)
Rename Table.RenameColumns(t, {{"Title", "Name"}})
Replace values Table.ReplaceValue(t, "", null, Replacer.ReplaceValue, {"Plant"})
Merge (join) Table.NestedJoin(a, {"PlantId"}, b, {"ID"}, "P", JoinKind.LeftOuter) then Table.ExpandTableColumn
Append (union) Table.Combine({t2024, t2025, t2026})
Group Table.Group(t, {"Plant"}, {{"Count", each Table.RowCount(_), Int64.Type}})
Pivot / unpivot Table.Pivot, Table.UnpivotOtherColumns
Dedupe Table.Distinct(t, {"SKU"})
Text Text.Trim, Text.Upper, Text.Split, Text.Contains
Dates Date.From, DateTime.LocalNow(), Date.AddDays, Date.StartOfMonth

#Custom function + REST API paging

Call a paged REST API and combine pagesPower Query M
let
    GetPage = (url as text) as record =>
        let
            resp = Json.Document(Web.Contents(url, [Headers = [Accept = "application/json"]]))
        in
            resp,
    Pages = List.Generate(
        () => GetPage("https://api.contoso.com/products?page=1"),
        each _ <> null,
        each if Record.HasFields(_, "next") and _[next] <> null then GetPage(_[next]) else null,
        each _[items]
    ),
    Rows   = List.Combine(Pages),
    AsTable = Table.FromRecords(Rows)
in
    AsTable
Use relative paths with Web.Contents

For scheduled refresh, keep the base URL static and pass the variable part via RelativePath and Query options (Web.Contents("https://api.contoso.com", [RelativePath = "products", Query = [page = "2"]])). Otherwise the service may consider the source "dynamic" and refuse to refresh.

#Interview questions

Q1What does each mean in M?

It is shorthand for a function with one parameter named _: each [Status] = "Open" is (_) => _[Status] = "Open". It is used in row-wise operations like SelectRows and AddColumn.

Q2Why might a dataflow that works in the editor fail on scheduled refresh?

Common causes are dynamic data sources (URLs built from variables, so use RelativePath and Query), missing gateway or credentials for on-prem sources, privacy level conflicts when combining sources, and timeouts on non-folding transformations.
