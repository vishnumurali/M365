Query Folding & Dataflow Performance – Make the Source Do the Work

Understand query folding, how to check it (View native query, folding indicators), which steps break folding, ordering steps for performance, handling SharePoint and API sources that don't fold, and troubleshooting slow or failing refreshes.

Query folding means Power Query translates your steps into the source's native query language (SQL, OData), so filtering, column selection and aggregation happen at the source. Folding queries are fast and light. Non-folding ones pull everything and process it in the mashup engine.

#Steps that usually fold vs break folding (relational sources)

Usually fold Often break folding
Filter rows, remove/select columns Index column, Table.Buffer
Sort, group by, simple joins Custom M functions per row, Text.Proper style text ops (source-dependent)
Rename, change type (simple) Merging queries from different sources
Top N Pivot/unpivot (source-dependent), Table.AddColumn with complex logic

Rule of thumb: put filters and column selection first, and non-folding steps as late as possible.

#Checking folding

  • Right-click a step → View native query (enabled = folding up to that step).
  • Folding indicators in Power Query Online show which steps fold.
  • Query diagnostics for detailed timing.

#Sources that don't fold well

SharePoint lists (folding is limited, with large lists downloaded in pages), Excel/CSV files, and most REST APIs. Mitigations: filter with source options (SharePoint views, API query parameters), reduce columns early, and stage into Dataverse or a Lakehouse once, then transform from there.

#Interview questions

Q1What is query folding and why does it matter?

Folding pushes transformation steps back to the data source as native queries, so only the needed data is transferred and processed by the source engine. Without folding, Power Query downloads more data and processes it locally, which is slower, heavier and can time out.

Q2How can you tell whether a step folds?

Use View native query on the step (if available, it folds), or check step folding indicators in Power Query Online.
