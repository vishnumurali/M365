SharePoint, SPFx and the Power Platform cover the front end and low-code logic. Azure supplies everything else: secure APIs, background processing, storage at scale, integration and AI.

#Interview questions

Q1Which Azure services do you typically pair with SPFx?

Entra ID (an app registration exposing an API), Azure Functions or App Service for the API, Key Vault and managed identities for secrets, a data store (SQL, Cosmos DB, Table or Blob storage), and Application Insights for monitoring.

Q2Why put an API between Power Platform or SPFx and back-end systems?

To keep secrets and privileged access server-side, enforce validation and business rules, shape and aggregate data, apply caching and throttling, and present a stable contract to many clients.
