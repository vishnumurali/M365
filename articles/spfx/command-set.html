ListView Command Set – Custom Buttons in the Command Bar and Context Menu

Add custom commands to modern lists and libraries, covering command visibility based on selection, listViewStateChangedEvent, opening dialogs, calling REST or Power Automate on selected items, and registering the command set on specific list templates.

A ListView Command Set adds buttons to a list or library's command bar and context menu (ECB). It is the modern replacement for classic ribbon custom actions: "Send for approval", "Generate PDF", "Copy to archive", "Export to Excel with template".

ApprovalCommandSet.tsTypeScript
import {
  BaseListViewCommandSet, Command, IListViewCommandSetExecuteEventParameters, ListViewStateChangedEventArgs
} from '@microsoft/sp-listview-extensibility';
import { Dialog } from '@microsoft/sp-dialog';
import { SPHttpClient } from '@microsoft/sp-http';

export interface IApprovalCommandSetProperties { flowUrl: string; }

export default class ApprovalCommandSet extends BaseListViewCommandSet<IApprovalCommandSetProperties> {
  public async onInit(): Promise<void> {
    const cmd: Command = this.tryGetCommand('SEND_APPROVAL');
    cmd.visible = false;
    this.context.listView.listViewStateChangedEvent.add(this, this._onStateChanged);
  }

  private _onStateChanged = (args: ListViewStateChangedEventArgs): void => {
    const cmd = this.tryGetCommand('SEND_APPROVAL');
    const rows = this.context.listView.selectedRows ?? [];
    // visible only when 1+ items selected and none already submitted
    cmd.visible = rows.length > 0 && rows.every(r => r.getValueByName('Status') === 'Draft');
    this.raiseOnChange();
  };

  public async onExecute(event: IListViewCommandSetExecuteEventParameters): Promise<void> {
    if (event.itemId !== 'SEND_APPROVAL') return;
    const ids = (event.selectedRows ?? []).map(r => Number(r.getValueByName('ID')));
    const list = this.context.pageContext.list!;
    const web = this.context.pageContext.web.absoluteUrl;

    for (const id of ids) {
      await this.context.spHttpClient.post(
        `${web}/_api/web/lists(guid'${list.id}')/items(${id})/ValidateUpdateListItem`,
        SPHttpClient.configurations.v1,
        { body: JSON.stringify({ formValues: [{ FieldName: 'Status', FieldValue: 'Submitted' }], bNewDocumentUpdate: false }) });
    }
    await Dialog.alert(`${ids.length} item(s) sent for approval.`);
  }
}

elements.xml – register for all custom lists (template 100)XML
<CustomAction Title="ApprovalCommandSet" RegistrationId="100" RegistrationType="List"
  Location="ClientSideExtension.ListViewCommandSet.CommandBar"
  ClientSideComponentId="a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d"
  ClientSideComponentProperties="{&quot;flowUrl&quot;:&quot;&quot;}" />

Locations: ClientSideExtension.ListViewCommandSet.CommandBar, .ContextMenu, or ClientSideExtension.ListViewCommandSet (both). Use RegistrationId="101" for document libraries.

Prefer

listViewStateChangedEvent Older samples override onListViewUpdated, which is deprecated. Subscribe to this.context.listView.listViewStateChangedEvent (SPFx 1.16+) to react to selection, view and folder changes.

#Interview questions

Q1How do you show a command only when exactly one document is selected?

In the listViewStateChangedEvent handler, set command.visible = this.context.listView.selectedRows?.length === 1 and call this.raiseOnChange() to refresh the command bar.

Q2How do you target a command set to document libraries only?

Register the custom action with RegistrationType="List" and RegistrationId="101" (document library template) in elements.xml, or in the Tenant Wide Extensions list with the list template filter set to 101.
