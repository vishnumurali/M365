Form Customizer – Replace SharePoint List New/Edit/Display Forms with React

Build a custom list form with the SPFx form customizer, covering display modes, loading and saving the item, validation, formSaved/formClosed, and binding the component to a content type with PnP PowerShell, with a comparison against Power Apps forms.

The form customizer (GA in SPFx 1.15) lets developers replace the New, Edit and Display forms of a list or content type with their own React component. It is the pro-code alternative to Power Apps forms, with full control, native performance and Git-based ALM.

#How it works

#The customizer class

DeviationFormFormCustomizer.tsTypeScript
import { BaseFormCustomizer } from '@microsoft/sp-listview-extensibility';
import { FormDisplayMode } from '@microsoft/sp-core-library';
import * as React from 'react';
import * as ReactDOM from 'react-dom';
import { spfi, SPFx } from '@pnp/sp';
import '@pnp/sp/webs'; import '@pnp/sp/lists'; import '@pnp/sp/items';
import DeviationForm from './components/DeviationForm';

export default class DeviationFormFormCustomizer extends BaseFormCustomizer<{}> {
  private _sp = spfi();

  public async onInit(): Promise<void> {
    this._sp = spfi().using(SPFx(this.context));
    return super.onInit();
  }

  public render(): void {
    ReactDOM.render(React.createElement(DeviationForm, {
      displayMode: this.displayMode,              // New | Edit | Display
      itemId: this.context.itemId,                // undefined for New
      listGuid: this.context.list.guid.toString(),
      sp: this._sp,
      onSave: this._onSave,
      onClose: this._onClose
    }), this.domElement);
  }

  public onDispose(): void {
    ReactDOM.unmountComponentAtNode(this.domElement);
    super.onDispose();
  }

  private _onSave = (): void => { this.formSaved(); };   // tells SharePoint the item was saved
  private _onClose = (): void => { this.formClosed(); }; // cancel / close
}

#The form component (React + validation)

components/DeviationForm.tsxTSX
import * as React from 'react';
import { FormDisplayMode } from '@microsoft/sp-core-library';
import { TextField, Dropdown, DatePicker, PrimaryButton, DefaultButton, MessageBar, MessageBarType, Stack } from '@fluentui/react';

const AREAS = ['Production', 'Warehouse', 'Lab'].map(a => ({ key: a, text: a }));

export default function DeviationForm(props: any): JSX.Element {
  const { displayMode, itemId, listGuid, sp, onSave, onClose } = props;
  const readOnly = displayMode === FormDisplayMode.Display;
  const [item, setItem] = React.useState<any>({ Title: '', Area: '', Severity: 'Minor', DueDate: undefined });
  const [errors, setErrors] = React.useState<string[]>([]);
  const [saving, setSaving] = React.useState(false);
  const list = sp.web.lists.getById(listGuid);

  React.useEffect(() => {
    if (displayMode !== FormDisplayMode.New && itemId) {
      list.items.getById(itemId).select('Title', 'Area', 'Severity', 'DueDate')()
        .then((i: any) => setItem({ ...i, DueDate: i.DueDate ? new Date(i.DueDate) : undefined }));
    }
  }, [itemId]);

  const validate = (): string[] => {
    const e: string[] = [];
    if (!item.Title || item.Title.trim().length < 5) e.push('Title must have at least 5 characters.');
    if (!item.Area) e.push('Area is required.');
    if (item.Severity === 'Critical' && !item.DueDate) e.push('Critical deviations need a due date.');
    if (item.DueDate && item.DueDate < new Date(new Date().toDateString())) e.push('Due date cannot be in the past.');
    return e;
  };

  const save = async (): Promise<void> => {
    const e = validate(); setErrors(e); if (e.length) return;
    setSaving(true);
    const body = { Title: item.Title, Area: item.Area, Severity: item.Severity, DueDate: item.DueDate?.toISOString() ?? null };
    try {
      if (displayMode === FormDisplayMode.New) await list.items.add(body);
      else await list.items.getById(itemId).update(body);
      onSave();
    } catch (err: any) { setErrors([err.message]); setSaving(false); }
  };

  return (
    <Stack tokens={{ childrenGap: 12 }} style={{ padding: 20, maxWidth: 560 }}>
      {errors.length > 0 && <MessageBar messageBarType={MessageBarType.error}>{errors.map(e => <div key={e}>{e}</div>)}</MessageBar>}
      <TextField label="Title" required readOnly={readOnly} value={item.Title} onChange={(_, v) => setItem({ ...item, Title: v })} />
      <Dropdown label="Area" required disabled={readOnly} options={AREAS} selectedKey={item.Area} onChange={(_, o) => setItem({ ...item, Area: o?.key })} />
      <Dropdown label="Severity" disabled={readOnly} selectedKey={item.Severity}
        options={['Minor', 'Major', 'Critical'].map(s => ({ key: s, text: s }))} onChange={(_, o) => setItem({ ...item, Severity: o?.key })} />
      {(item.Severity !== 'Minor') && /* conditional field */
        <DatePicker label="Due date" disabled={readOnly} value={item.DueDate} onSelectDate={d => setItem({ ...item, DueDate: d || undefined })} />}
      <Stack horizontal tokens={{ childrenGap: 8 }}>
        {!readOnly && <PrimaryButton text={saving ? 'Saving…' : 'Save'} disabled={saving} onClick={save} />}
        <DefaultButton text={readOnly ? 'Close' : 'Cancel'} onClick={onClose} />
      </Stack>
    </Stack>
  );
}

#Binding the form to a content type

Form customizers are associated with a content type through three properties:

PnP PowerShell: use the customizer for New, Edit and DisplayPowerShell
Connect-PnPOnline -Url https://contoso.sharepoint.com/sites/quality -Interactive -ClientId $clientId
$componentId = "c0ffee00-1234-4abc-9def-001122334455"   # from the manifest
$ct = Get-PnPContentType -List "Deviations" -Identity "Item"
$ct.NewFormClientSideComponentId     = $componentId
$ct.EditFormClientSideComponentId    = $componentId
$ct.DisplayFormClientSideComponentId = $componentId
$ct.Update($false)
Invoke-PnPQuery

To debug against a real list, serve.json uses a URL like .../_layouts/15/SPListForm.aspx?debugManifestsFile=https://localhost:4321/temp/manifests.js&loadSPFX=true&componentId=<id>&PageType=8&RootFolder=/sites/quality/Lists/Deviations (PageType 8 = New, 6 = Edit, 4 = Display).

#Form customizer vs Power Apps vs form formatting

Need Best choice
Show/hide fields, header/footer Form formatting
Maker-built form with connectors, offline, quick iterations Power Apps list form
Complex validation, API calls, reusable React components, Git ALM, best performance SPFx form customizer

#Interview questions

Q1How does SharePoint know to use your form customizer?

The content type's NewFormClientSideComponentId, EditFormClientSideComponentId and DisplayFormClientSideComponentId properties hold the customizer's component ID (plus optional ...ClientSideComponentProperties). The list's modern form then loads your component instead of the default form.

Q2What must the form call after saving?

this.formSaved(), so SharePoint closes the form panel and refreshes the view. this.formClosed() is called for cancel. The customizer itself performs the actual item create or update, for example with PnPjs.
