The SharePoint Connector in Depth – Get Items, OData Filters, Files, Folders & Permissions

Master the SharePoint connector actions, covering Get items with OData filter queries for every column type, views and row limits, create/update with people and lookups, file and folder actions, copy/move, and permission-related actions.

#Get items: the action you use most

Setting Purpose
Filter Query OData $filter evaluated server-side, so always use it instead of filtering after
Order By Created desc
Top Count Rows per call (default 100, max 5,000)
Limit Columns by View Only return a view's columns (faster, smaller payloads)
Settings → Pagination Fetch beyond Top Count (threshold up to 100,000 on premium plans)

#OData filter cheat sheet (use internal names)

Filter Query examplesOData
Status eq 'Open'                                            // choice / text
Status ne 'Closed' and Severity eq 'Critical'
Amount gt 10000                                             // number
DueDate lt '2026-10-08'                                     // date (yyyy-MM-dd)
DueDate le '@{formatDateTime(utcNow(),'yyyy-MM-dd')}'       // dynamic date via expression
startswith(Title, 'DEV-')                                   // text starts with
substringof('pump', Title)                                  // contains (not efficient on big lists)
Owner/EMail eq 'jane@contoso.com'                           // person (EMail, Title)
Plant/Id eq 3                                               // lookup by id  (also: Plant/Title eq 'Bangalore')
IsActive eq 1                                               // yes/no
Department eq null                                          // empty
Created ge datetime'2026-01-01T00:00:00Z'                   // datetime literal form
Internal names and the 5,000 threshold

Filter columns by internal name (Due_x0020_Date if created with a space). On lists with more than 5,000 items, the first filtered column must be indexed or the action fails with a threshold error.

#Files and folders

Useful file actions: Get file metadata, Get file content (using path), Check out/in, Copy file, Move file, Create sharing link for a file or folder, Grant access to an item or a folder, Stop sharing an item or a file.

#Interview questions

Q1How do you filter Get items by a person column?

Use the person field's sub-property in the OData filter, for example Owner/EMail eq 'jane@contoso.com' (note the capital E in EMail). The column should be indexed on large lists.

Q2Why should you avoid filtering with a Condition or Filter array after Get items?

Because Get items would download up to the row limit and filtering would happen in the flow, which is slow, uses API calls and silently misses rows beyond the limit. A Filter Query runs server-side and returns only matching rows.
