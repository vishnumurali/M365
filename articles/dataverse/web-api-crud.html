The Dataverse Web API is an OData v4 REST endpoint: https://<org>.<region>.dynamics.com/api/data/v9.2/. Any language can call it with an Entra ID token for the environment URL.

#Headers you always send

Standard headersHTTP
Authorization: Bearer <token for https://contoso.crm4.dynamics.com>
Accept: application/json
Content-Type: application/json; charset=utf-8
OData-MaxVersion: 4.0
OData-Version: 4.0
Prefer: odata.include-annotations="OData.Community.Display.V1.FormattedValue"

#READ

Query with select, filter, expand, order, pagingHTTP
GET /api/data/v9.2/cr8a1_deviations?$select=cr8a1_name,cr8a1_severity,cr8a1_duedate
    &$filter=statecode eq 0 and cr8a1_severity eq 100000002 and cr8a1_duedate lt 2026-11-01
    &$expand=cr8a1_Plant($select=cr8a1_name)
    &$orderby=cr8a1_duedate asc
    &$top=50
Prefer: odata.maxpagesize=50

→ { "value": [ ... ], "@odata.nextLink": "…$skiptoken=…" }
Function Example
contains / startswith / endswith contains(cr8a1_name,'pump')
Lookup filter _cr8a1_plant_value eq 6f1c2a9e-…
Query functions Microsoft.Dynamics.CRM.LastXDays(PropertyName='createdon',PropertyValue=7)
Count $count=true (max 5,000 returned in count)
Aggregation $apply=groupby((cr8a1_severity),aggregate($count as total))

#CREATE · UPDATE · UPSERT · DELETE

Create (return the row) with a lookupHTTP
POST /api/data/v9.2/cr8a1_deviations
Prefer: return=representation

{ "cr8a1_name": "Cold room excursion", "cr8a1_severity": 100000001,
  "cr8a1_Plant@odata.bind": "/cr8a1_plants(6f1c2a9e-3b4d-4e5f-8a7b-9c0d1e2f3a4b)" }
Update (PATCH) — If-Match prevents accidental createHTTP
PATCH /api/data/v9.2/cr8a1_deviations(0a1b2c3d-…)
If-Match: *

{ "statecode": 1, "statuscode": 2, "cr8a1_closurecomment": "Validated" }
Upsert by alternate keyHTTP
PATCH /api/data/v9.2/cr8a1_products(cr8a1_sku='SKU-10042')

{ "cr8a1_name": "Pressure sensor X2" }
Delete / disassociateHTTP
DELETE /api/data/v9.2/cr8a1_deviations(0a1b2c3d-…)
DELETE /api/data/v9.2/cr8a1_deviations(0a1b2c3d-…)/cr8a1_deviation_product/$ref?$id=[org]/api/data/v9.2/cr8a1_products(…)

#JavaScript (fetch) wrapper

Minimal client (token from MSAL or AadHttpClient)JavaScript
async function dv(method, path, body, extraHeaders = {}) {
  const res = await fetch(`${ORG}/api/data/v9.2/${path}`, {
    method,
    headers: {
      Authorization: `Bearer ${await getToken()}`, Accept: 'application/json',
      'Content-Type': 'application/json; charset=utf-8', 'OData-MaxVersion': '4.0', 'OData-Version': '4.0',
      Prefer: 'odata.include-annotations="*"', ...extraHeaders
    },
    body: body ? JSON.stringify(body) : undefined
  });
  if (!res.ok) throw new Error((await res.json()).error?.message ?? res.statusText);
  return res.status === 204 ? null : res.json();
}

const open = await dv('GET', "cr8a1_deviations?$select=cr8a1_name&$filter=statecode eq 0&$top=10");
const created = await dv('POST', 'cr8a1_deviations', { cr8a1_name: 'New' }, { Prefer: 'return=representation' });
await dv('PATCH', `cr8a1_deviations(${created.cr8a1_deviationid})`, { cr8a1_name: 'Renamed' }, { 'If-Match': '*' });
await dv('DELETE', `cr8a1_deviations(${created.cr8a1_deviationid})`);

#$batch (transactional changesets)

Two creates in one transactionHTTP
POST /api/data/v9.2/$batch
Content-Type: multipart/mixed; boundary=batch_1

--batch_1
Content-Type: multipart/mixed; boundary=changeset_1

--changeset_1
Content-Type: application/http
Content-Transfer-Encoding: binary
Content-ID: 1

POST /api/data/v9.2/cr8a1_deviations HTTP/1.1
Content-Type: application/json

{"cr8a1_name":"Batch A"}
--changeset_1
Content-Type: application/http
Content-Transfer-Encoding: binary
Content-ID: 2

POST /api/data/v9.2/cr8a1_capaactions HTTP/1.1
Content-Type: application/json

{"cr8a1_name":"Action for A","cr8a1_Deviation@odata.bind":"$1"}
--changeset_1--
--batch_1--

$1 references the row created by Content-ID 1 in the same changeset, so either both succeed or both roll back.

#Interview questions

Q1How do you set a lookup when creating a row with the Web API?

Use @odata.bind on the single-valued navigation property: "cr8a1_Plant@odata.bind": "/cr8a1_plants(<guid>)". Use the navigation property name (case-sensitive) and the entity set name of the target.

Q2How do you prevent PATCH from creating a new row?

PATCH performs an upsert by default. Add If-Match: * to require that the row exists (update only). Use If-None-Match: * to require that it does not exist (create only).

Q3How do you get choice labels instead of numbers?

Send Prefer: odata.include-annotations="OData.Community.Display.V1.FormattedValue" and read the …@OData.Community.Display.V1.FormattedValue property next to each choice or lookup value.
