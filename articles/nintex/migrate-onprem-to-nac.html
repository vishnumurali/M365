Migrating Nintex for SharePoint (On-Prem) to NAC or Hybrid

Paths for Nintex Workflow and Forms on SharePoint 2013–SE, covering moving to NAC with SharePoint Online, hybrid with Nintex Gateway while SharePoint stays on-prem, inventory with NWAdmin, mapping farm-only actions, forms and UDAs, and sequencing with the SharePoint content migration.

#Choose the target

#Sequencing with a SharePoint migration

  1. Inventory workflows (NWAdmin -o FindWorkflows), forms, UDAs, constants and scheduled workflows.
  2. Migrate content (ShareGate copies lists and libraries; Nintex definitions don't execute in SPO).
  3. Rebuild workflows in NAC pointing at the new SPO lists (connections, start events).
  4. Rebuild forms as NAC forms (or Power Apps, depending on strategy).
  5. Cut over per site/process, and archive history (export Nintex history to CSV or a list if needed for audit).

#On-prem only features to redesign

On-prem feature Cloud approach
Execute SQL / Query LDAP Xtension over an API, or Nintex Gateway hybrid actions
Workflow constants (credentials) NAC connections
UDAs Component workflows
Farm-level actions (create site collection, provision AD user) Graph/Entra via Xtension or Power Automate
Site workflows on schedules Scheduled start event
LazyApproval Express approvals
Nintex history stays behind

Workflow history and Nintex databases don't migrate to NAC. If you need an audit trail, export it before decommissioning, or rely on status and approval history columns maintained on the items.

#Interview questions

Q1Do Nintex on-prem workflows run in SharePoint Online after migrating content?

No. Nintex for SharePoint is a farm product. After content moves to SPO, workflows must be rebuilt in NAC (or another platform) using the SharePoint Online connector.

Q2What does Nintex Gateway enable?

Hybrid scenarios where NAC workflows interact with on-premises systems (SharePoint Server, SQL, file shares) through an outbound-connected agent in your network, which is useful when SharePoint stays on-prem but you want cloud workflow capabilities.
