PnP PowerShell Essentials – Connect, Query, Bulk-Update and Report (2026 Edition)

Practical PnP PowerShell for SharePoint Online, covering installing on PowerShell 7, registering your own Entra app (required since 2024), interactive and certificate connections, and 15 copy-ready scripts for lists, files, permissions, sites and reporting.

PnP PowerShell is the open-source, cross-platform module with 700+ cmdlets for SharePoint Online, Teams, Planner, Entra ID and more. It is maintained by the Microsoft 365 PnP community and is the most productive way to script SharePoint.

#Setup (2026)

Install on PowerShell 7.4+PowerShell
Install-Module PnP.PowerShell -Scope CurrentUser
Import-Module PnP.PowerShell
Get-Module PnP.PowerShell -ListAvailable | Select-Object Name, Version
Bring your own Entra app

Since September 2024 the shared multi-tenant "PnP Management Shell" app was removed. You must register your own Entra ID app for PnP PowerShell and pass its client ID when connecting.

One-time: register an app for interactive usePowerShell
Register-PnPEntraIDAppForInteractiveLogin -ApplicationName "PnP PowerShell - Contoso" -Tenant contoso.onmicrosoft.com -Interactive
# Note the returned Client ID; store it in $env:PNP_CLIENTID or your profile

#Connection options

ConnectPowerShell
$clientId = $env:PNP_CLIENTID
Connect-PnPOnline -Url "https://contoso.sharepoint.com/sites/quality" -Interactive -ClientId $clientId

# App-only with certificate (register with Register-PnPEntraIDApp, grant Sites.FullControl.All or Sites.Selected)
Connect-PnPOnline -Url "https://contoso.sharepoint.com/sites/quality" -ClientId $clientId `
  -Tenant "contoso.onmicrosoft.com" -CertificatePath ".\pnp-app.pfx" -CertificatePassword (Read-Host -AsSecureString)

#15 scripts you will reuse

1–5: lists and itemsPowerShell
# 1. List all lists with item counts (excluding hidden)
Get-PnPList | Where-Object Hidden -eq $false | Select-Object Title, ItemCount, LastItemUserModifiedDate

# 2. Export a list to CSV (paged, all items)
Get-PnPListItem -List "Deviations" -PageSize 2000 -Fields "Title","Status","Owner" |
  ForEach-Object { [pscustomobject]@{ Id = $_.Id; Title = $_["Title"]; Status = $_["Status"]; Owner = $_["Owner"].Email } } |
  Export-Csv .\deviations.csv -NoTypeInformation

# 3. Bulk import from CSV with batching (fast)
$batch = New-PnPBatch
Import-Csv .\new-items.csv | ForEach-Object {
  Add-PnPListItem -List "Deviations" -Values @{ Title = $_.Title; Status = "Submitted" } -Batch $batch
}
Invoke-PnPBatch -Batch $batch

# 4. Bulk update with a filter (CAML)
Get-PnPListItem -List "Deviations" -Query "<View><Query><Where><Eq><FieldRef Name='Status'/><Value Type='Choice'>Draft</Value></Eq></Where></Query></View>" |
  ForEach-Object { Set-PnPListItem -List "Deviations" -Identity $_.Id -Values @{ Status = "Submitted" } -UpdateType SystemUpdate }

# 5. Add an index to a column
Set-PnPField -List "Deviations" -Identity "Status" -Values @{ Indexed = $true }
6–10: files and permissionsPowerShell
# 6. Upload a folder of files with metadata
Get-ChildItem .\SOPs -File | ForEach-Object {
  Add-PnPFile -Path $_.FullName -Folder "Shared Documents/SOPs" -Values @{ DocumentType = "SOP" }
}

# 7. Download a whole library folder
Get-PnPFolderItem -FolderSiteRelativeUrl "Shared Documents/SOPs" -ItemType File |
  ForEach-Object { Get-PnPFile -Url $_.ServerRelativeUrl -Path .\backup -AsFile -Force }

# 8. Report unique permissions on items in a library
Get-PnPListItem -List "Documents" -PageSize 2000 -Fields "FileRef","HasUniqueRoleAssignments" |
  Where-Object { $_["HasUniqueRoleAssignments"] } | Select-Object @{n='Path';e={$_["FileRef"]}}

# 9. Grant a group Edit on a library and break inheritance
Set-PnPList -Identity "Contracts" -BreakRoleInheritance -CopyRoleAssignments
Set-PnPListPermission -Identity "Contracts" -Group "Legal Members" -AddRole "Edit"

# 10. Find sharing links (anonymous/organization) on a site
Get-PnPFileSharingLink -Identity "/sites/quality/Shared Documents/report.xlsx"
11–15: sites and tenantPowerShell
# 11. All sites with storage and last activity (admin)
Connect-PnPOnline -Url https://contoso-admin.sharepoint.com -Interactive -ClientId $clientId
Get-PnPTenantSite -Detailed | Select-Object Url, Template, StorageUsageCurrent, LastContentModifiedDate | Export-Csv .\sites.csv -NoTypeInformation

# 12. Sites without a second owner (ownerless risk)
Get-PnPTenantSite -Detailed | Where-Object { $_.Owner -eq $null -or $_.Owner -eq "" } | Select-Object Url

# 13. Add site collection admin across many sites
Get-Content .\sites.txt | ForEach-Object { Set-PnPTenantSite -Identity $_ -Owners "spadmin@contoso.com" }

# 14. Lock a site read-only (migration cut-over)
Set-PnPTenantSite -Identity https://contoso.sharepoint.com/sites/finance -LockState ReadOnly

# 15. Install an SPFx package to the tenant app catalog and deploy it
Add-PnPApp -Path .\deviation-webparts.sppkg -Scope Tenant -Publish -SkipFeatureDeployment
Throttling-friendly scripts

Use -PageSize and batches, add Start-Sleep between heavy loops, run large jobs out of hours, and prefer app-only connections with a decorated user agent for long-running migrations.

#PnP PowerShell vs SPO Management Shell vs CLI for Microsoft 365

PnP PowerShell SPO Management Shell CLI for Microsoft 365
Scope Site + tenant + Teams + Entra Tenant admin only Everything, cross-platform
Platform PowerShell 7 (Windows/macOS/Linux) Windows PowerShell Node.js (bash, zsh, PowerShell)
Auth Own Entra app (interactive, cert, MI) Admin sign-in Own Entra app
Best for Day-to-day dev/admin scripting Tenant settings (Set-SPOTenant) CI/CD pipelines, bash users

#Interview questions

Q1What changed for PnP PowerShell authentication in 2024?

The shared "PnP Management Shell" multi-tenant Entra app was removed. Every tenant must register its own Entra app (for example with Register-PnPEntraIDAppForInteractiveLogin) and pass -ClientId when connecting.

Q2How do you speed up adding thousands of items with PnP PowerShell?

Use batching: create a batch with New-PnPBatch, pass -Batch to Add-PnPListItem and Set-PnPListItem, then call Invoke-PnPBatch, which sends grouped requests instead of one call per item.

Q3How would you run PnP PowerShell unattended in Azure?

In Azure Automation or Azure Functions, with a managed identity (Connect-PnPOnline -ManagedIdentity) granted the required Graph or SharePoint permissions (ideally Sites.Selected), or with an Entra app and certificate stored in Key Vault.
