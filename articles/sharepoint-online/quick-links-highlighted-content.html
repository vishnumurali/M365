Quick Links & Highlighted Content – Layouts, Filters, KQL and Audience Targeting

The two most versatile modern web parts, with all six Quick links layouts, icons and audiences, and Highlighted content sources, filters, sort options, custom KQL queries and performance tips.

Each link can have a title, description, thumbnail (auto, custom image or icon), alternative text, and an audience (Entra ID / M365 groups) if audience targeting is enabled on the web part.

#Highlighted content: dynamic roll-ups

Because Highlighted content uses search under the hood (except when the source is a single library in "document library" mode), new content appears after crawling, typically within minutes, and security trimming is automatic.

#Custom KQL examples

Useful Highlighted content queriesKQL
// Policies from any site, newest first (use with "Custom query" mode)
ContentType:"Policy Document" IsDocument:true

// Training videos tagged for Plant A, last 90 days
FileExtension:mp4 RefinableString05:"Plant A" LastModifiedTime>={Today-90}

// News posts from sites in the HR hub (DepartmentId = the hub site's ID) by the HR comms author
DepartmentId:"6f1c2a9e-3b4d-4e5f-8a7b-9c0d1e2f3a4b" PromotedState:2 Author:"HR Communications"

// Deviation SOPs in quality sites (path scope)
path:"https://contoso.sharepoint.com/sites/quality" ContentType:SOP
Managed properties for filters

To filter on your own site columns (e.g. "Plant"), map their crawled property (ows_Plant) to a reusable RefinableString managed property in the SharePoint admin center search schema. Then use RefinableString05:"Plant A" in queries and refiners.

#Performance and governance tips

  • Prefer site or hub scope over "All sites" when possible. It is faster and more relevant.
  • Limit items shown (6–12) and provide a See all link to a search vertical or library view.
  • Use audience targeting on Quick links for role-based shortcuts (e.g. managers see approval links).
  • Avoid duplicating the same Highlighted content query on dozens of pages. Create a page template.

#Interview questions

Q1How does Highlighted content get its data?

For most sources it queries the search index (with security trimming), so freshly added content appears after crawling. When pointed at a single document library with simple filters it can read the library directly.

Q2How do you filter Highlighted content by a custom column across sites?

Map the column's crawled property to a refinable or queryable managed property in the search schema, wait for re-crawl, then use the custom query (KQL) mode, for example RefinableString05:"Plant A".

Q3What is the most compact Quick links layout and when would you use it?

Compact: small icon-and-title chips. It suits one-third columns, vertical sections or long lists of utility links where images add no value.
