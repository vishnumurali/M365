Dataverse Interview Questions

Tables and columns, relationships and cascade, the security model, Web API and SDK, plug-ins, formula and rollup columns, auditing, integration, capacity and limits.

Deep dives: Dataverse tab.

#Data modeling

Q1What was Dataverse previously called?

Common Data Service (renamed November 2020).

Q2User-owned vs organization-owned tables?

User/team-owned tables have an Owner and support depth-based access. Organization-owned tables are all-or-nothing access.

Q3What are alternate keys for?

Uniquely identifying rows by business keys for integrations, upserts and lookup binding.

Q4Native vs manual N:N?

Native uses a hidden intersect table with no extra columns. Manual uses your own table, so you can add columns.

Q5What does Restrict delete do?

It blocks deleting a parent while children exist.

Q6Formula vs rollup column?

Formula: Power Fx computed at read time from the row and parents. Rollup: aggregates children asynchronously (hourly or on demand).

Q7Virtual vs elastic tables?

Virtual tables surface external data without copying. Elastic tables are Cosmos DB–backed for massive volumes with TTL.

#Security

Q8Access levels in security roles?

None, User, Business Unit, Parent: Child BUs, Organization.

Q9Owner team vs access team?

Owner teams own rows and have roles. Access teams share specific rows with a dynamic set of users.

Q10How do you hide a column from some users?

Column-level security with column security profiles.

Q11What is an Entra ID group team?

A team linked to an Entra group, so membership and roles flow from the group.

#Development

Q12How do you set a lookup in the Web API?

"nav@odata.bind": "/entityset(guid)" using the navigation property name.

Q13How do you prevent PATCH from creating rows?

Add If-Match: *.

Q14How do you get choice labels?

Prefer: odata.include-annotations="OData.Community.Display.V1.FormattedValue".

Q15Pipeline stages?

Pre-validation (10), pre-operation (20, in transaction), post-operation (40, sync in transaction or async).

Q16Pre/post images?

Snapshots of column values before or after the operation, registered on steps.

Q17How do you show a friendly error from a plug-in?

Throw InvalidPluginExecutionException in a synchronous step.

Q18Why use filtering attributes?

So update steps run only when relevant columns change, which improves performance and prevents loops.

Q19What are custom APIs?

Custom messages with typed parameters implemented by plug-ins, callable from the Web API, SDK and flows.

Q20FetchXML vs OData?

FetchXML supports aggregates, complex joins and outer joins. OData is simpler REST.

#Administration & integration

Q21Three levels for auditing?

Environment, table and column.

Q22Capacity types?

Database, File and Log.

Q23Service protection limits response?

HTTP 429 with Retry-After. Honour it and retry.

Q24Reliable outbound integration?

An async step to a Service Bus endpoint, consumed by an Azure Function.

Q25Synapse Link vs Fabric link?

Both replicate data for analytics. Fabric link exposes data in OneLake without managing the export pipeline.
