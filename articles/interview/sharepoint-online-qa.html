SharePoint Online Interview Questions

Modern sites and hubs, web parts, lists and formatting JSON, permissions and sharing, search, provisioning, governance, Copilot readiness and administration in SharePoint Online.

Deep dives: SharePoint Online tab.

#Sites & information architecture

Q1Team site vs communication site?

Team sites are for collaboration (usually M365-group connected). Communication sites are for broadcasting to many readers (no group, publishing layout).

Q2What is a hub site?

A site registered as a hub so associated sites share navigation, theme and search scope, and roll up news and events. It doesn't inherit permissions.

Q3Why flat architecture?

Independent site collections are easier to secure, move and govern, and hubs replace hierarchy for navigation.

Q4What is a home site?

The organization's landing site that powers global navigation (app bar) and Viva Connections.

Q5What does audience targeting do?

It filters navigation links, news and web part content by Entra or M365 groups. It is not a security feature.

Q6Private channel storage?

Each private or shared channel has its own SharePoint site with separate membership.

Q7What is the site storage limit and tenant pool?

Up to 25 TB per site. The tenant pool is 1 TB + 10 GB per licence, plus add-ons.

#Pages & web parts

Q8News vs Highlighted content web part?

News shows only news posts with news features. Highlighted content shows any content via filters or KQL across scopes.

Q9Hero web part layouts?

Tiles (up to 5 in a grid) and Layers (stacked bands).

Q10How do you connect web parts?

Configure the target web part's "Connect to source" (dynamic data), for example a List web part filtering a Document library web part.

Q11What controls which iframes can be embedded?

HTML Field Security settings (allowed domains) at site and tenant level.

Q12What is an organization news site?

An admin-designated authoritative news source whose posts get priority and distinct styling.

#Lists, libraries & formatting

Q13Column formatting vs JSLink?

Column formatting is declarative JSON rendered safely in modern UI. JSLink was classic JavaScript rendering and isn't supported in modern views.

Q14How do you start a flow from a list column button?

Use column formatting customRowAction with action: executeFlow and the flow ID (the flow uses the "For a selected item" trigger).

Q15What can view formatting do?

Add row classes, replace row rendering (rowFormatter), define gallery cards (tileProps) and custom group headers.

Q16How do you show a field conditionally in the list form?

Use a conditional formula on the column in the form's "Edit columns" settings, e.g. =if([$Category]=='Hardware','true','false').

Q17Can you change the 5,000-item threshold in SPO?

No. Use indexed columns, filtered views, paging and archiving.

Q18Maximum indexed columns per list?
Q19Content type gallery vs content type hub?

The content type gallery in the SharePoint admin center replaces the classic hub for publishing content types tenant-wide.

Q20Major/minor versions and content approval?

Minor versions are drafts. Content approval requires an approver before items become visible to readers.

#Security & governance

Q21Sharing link types?

Anyone, People in your organization, People with existing access, and Specific people.

Q22How do M365 group members get site access?

Group owners map to Site Owners and members to Site Members automatically.

Q23Why avoid item-level unique permissions?

They create many security scopes, slowing permission checks, search and management, and approaching limits.

Q24What tools find oversharing before Copilot?

SharePoint Advanced Management data access governance reports, site access reviews, restricted access control, restricted content discovery, and Purview.

Q25Retention policy vs retention label?

Policies apply to whole locations. Labels apply to items, support records and disposition reviews.

Q26What is the Preservation Hold library?

It stores retained copies of edited or deleted content under retention.

Q27What does ConditionalAccessPolicy AllowLimitedAccess do?

It gives browser-only access (no download, print or sync) from unmanaged devices.

Q28Why keep custom script disabled?

Scripts bypass governance and break with updates. Use SPFx or formatting JSON instead. Admin-enabled custom script reverts after 24 hours.

#Provisioning & automation

Q29Site script vs PnP template?

Site scripts are limited JSON actions run by SharePoint on site creation. PnP templates are rich (pages, security, files) and run by PnP tools or Functions.

Q30What changed in PnP PowerShell auth in 2024?

The shared PnP Management Shell app was removed, so tenants must register their own Entra app and pass -ClientId.

Q31How do you speed up bulk item creation in PnP PowerShell?

Use New-PnPBatch and -Batch parameters, then Invoke-PnPBatch.

Q32How do you make a new column usable as a search refiner?

Map its crawled property to a RefinableString managed property and reindex the list or site.

Q33What are Graph connectors?

Connectors that ingest external content into the Microsoft Search index with ACLs for search and Copilot.

#Platform & modernization

Q34What is SharePoint Embedded?

Headless containers of files accessed via Graph by an owning application, billed by consumption, with data in the customer tenant.

Q35What retired in SPO on 2 April 2026?

SharePoint Add-ins, Azure ACS for SPO, and SharePoint 2013 workflows.

Q36How do you convert classic pages to modern?

Use PnP page transformation (ConvertTo-PnPPage) with web part mapping.

Q37What does "groupify" mean?

Connecting an existing classic team site to a new Microsoft 365 group.

Q38Where are files shared in a 1:1 Teams chat stored?

In the sender's OneDrive (Microsoft Teams Chat Files).

Q39What are SharePoint agents?

Copilot assistants scoped to selected sites, libraries or files with instructions and starter prompts, stored as .agent files.

Q40What is SharePoint Premium?

AI content services (formerly Syntex): document processing, autofill columns, taxonomy tagging, content assembly, eSignature, mostly pay-as-you-go.
