SPFx Interview Questions

SharePoint Framework fundamentals, lifecycle, React, property pane, extensions, ACEs, data access with SPHttpClient, PnPjs, Graph and AadHttpClient, permissions, deployment, CI/CD, performance and troubleshooting.

Deep dives: SPFx tab.

#Fundamentals

Q1What is SPFx?

A client-side development model for SharePoint, Teams, Viva and Outlook. TypeScript and React components run in the page under the user's context and are deployed via .sppkg packages.

Q2What component types exist?

Web parts, application customizers, field customizers, ListView command sets, form customizers, Adaptive Card Extensions and library components.

Q3Why can't SPFx hold secrets?

The code runs in the browser, so anything in the bundle is downloadable. Put secrets behind an Entra-protected API.

Q4What does the web part manifest id do and why keep it stable?

It identifies the component on every page. Changing it breaks existing instances ("web part not found").

Q5What is supportedHosts?

It declares where a web part can run: SharePointWebPart, TeamsTab, TeamsPersonalApp, TeamsMeetingApp, SharePointFullPage.

Q6What is the hosted workbench?

/_layouts/15/workbench.aspx on a real site, loading locally served bundles with a real page context.

Q7Why use nvm?

Each SPFx version supports specific Node versions, so you switch per project.

#Lifecycle & UI

Q8Where do you initialize PnPjs or Graph clients?

In onInit(), which runs once and can be async.

Q9Reactive vs non-reactive property pane?

Reactive applies each change immediately and re-renders. Non-reactive (disableReactivePropertyChanges) uses an Apply button.

Q10How do you load property pane dropdown options lazily?

In onPropertyPaneConfigurationStart(), then this.context.propertyPane.refresh().

Q11How do you migrate saved properties after a schema change?

Bump dataVersion and transform in onAfterDeserialize.

Q12How do you support section backgrounds?

Set supportsThemeVariants: true, consume the ThemeProvider service, and use semantic colors.

Q13What is dynamic data?

A mechanism for connected components: sources implement IDynamicDataCallables and consumers use DynamicProperty.

Q14Why unmount React in onDispose?

To avoid memory leaks and stale listeners during SPA navigation.

#Extensions

Q15What placeholders can an application customizer use?

PlaceholderName.Top and PlaceholderName.Bottom.

Q16Why handle navigation events in application customizers?

Modern SharePoint is a single-page app, so placeholders are recreated on navigation.

Q17How do you show a command only for one selected item?

In listViewStateChangedEvent, set command.visible = selectedRows.length === 1 and call raiseOnChange().

Q18How is a form customizer bound?

Through the content type's NewFormClientSideComponentId, EditFormClientSideComponentId and DisplayFormClientSideComponentId.

Q19Field customizer vs column formatting?

Formatting is declarative and needs no deployment. Field customizers are code for API calls or complex rendering.

Q20What are ACE card view and quick view?

The card view is the compact dashboard tile. The quick view is an Adaptive Card template opened on click, with actions handled in onAction.

#Data & APIs

Q21SPHttpClient vs fetch?

SPHttpClient handles auth context and the request digest automatically for SharePoint REST.

Q22PnPjs selective imports?

v3+ requires importing features (@pnp/sp/items). Without them, methods are missing.

Q23How do you batch with PnPjs?

const [batched, execute] = sp.batched(); queue operations on batched, then await execute().

Q24What client calls Graph?

MSGraphClientV3 via this.context.msGraphClientFactory.getClient('3').

Q25How do you call your own API?

aadHttpClientFactory.getClient('<App ID URI>') with a webApiPermissionRequests entry approved in API access.

Q26Why are approved API permissions tenant-wide?

All SPFx solutions share the "SharePoint Online Client Extensibility" principal.

Q27What is isDomainIsolated?

It runs web parts in an isolated iframe with their own Entra app, so permissions aren't shared.

Q28How does SPFx call Dataverse?

With AadHttpClient for the environment URL, requesting Dataverse / user_impersonation, plus Web API OData calls with the user's security role.

Q29Two secure ways to use Azure Table Storage?

Via an Azure Function with managed identity (recommended), or directly with an Azure Storage user_impersonation token plus RBAC and CORS.

#Deployment & DevOps

Q30includeClientSideAssets?

It packages bundles in the .sppkg, served from the M365 CDN via the app catalog.

Q31skipFeatureDeployment?

Enables tenant-wide deployment without per-site installation.

Q32Why bump the solution version?

So sites detect the upgrade and feature upgrade actions run.

Q33How do you deploy from a pipeline?

Build and package, then use CLI for M365 or PnP PowerShell with a certificate-authenticated Entra app to app add and app deploy.

Q34How do you roll back a bad release?

Redeploy the previous build with a higher version number, because downgrades aren't supported.

Q35How do you upgrade SPFx versions?

m365 spfx project upgrade --toVersion x --output md, apply the steps, switch Node, rebuild and test.

Q36What changed in recent toolchains?

Newer SPFx versions move from gulp to a Heft-based build with npm scripts.

#Quality & troubleshooting

Q37How do you debug extensions?

Use serve configurations, or append loadSPFX=true&debugManifestsFile=...&customActions={...} to a page URL.

Q38How do you unit test SPFx?

Jest with mocked services and React Testing Library, keeping SPFx context out of components.

Q39How do you reduce bundle size?

Targeted imports, dynamic import(), removing duplicate or heavy libraries, and library components for shared code.

Q40CORS error calling a Function?

Add the SharePoint origin (and localhost for dev) to the Function's CORS settings.

Q41What is m365 spfx doctor?

A CLI check of Node, npm, TypeScript and SPFx package compatibility for a project.
