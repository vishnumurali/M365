SharePoint On-Premises Interview Questions

Farm architecture, service applications, SSOM and CSOM, event receivers, add-ins, workflows, search, upgrades and administration, with crisp answers from basics to architect level.

#Fundamentals

Q1What is the hierarchy of objects in SharePoint Server?

Farm → web applications → content databases → site collections → sites (webs) → lists/libraries → items/documents. Service applications are shared across web applications via proxies.

Q2What is a web application?

An IIS website plus SharePoint configuration (URLs per zone, authentication provider, app pool, managed paths, policies). It hosts site collections stored in its content databases.

Q3Difference between a site collection and a subsite?

A site collection is the top-level container with its own quota, admins, features and recycle bin stage 2, stored in one content database. Subsites live inside it and can inherit permissions and navigation.

Q4What are managed paths?

URL prefixes under a web application where site collections are created: wildcard (/sites/*) or explicit (/search).

Q5What are Alternate Access Mappings?

Mappings between public URLs and internal URLs per zone, so SharePoint renders correct links behind proxies and load balancers.

Q6What is stored in the configuration database?

Farm-wide settings: servers, services, web applications, solutions, timer job definitions and topology.

Q7Standard vs Enterprise edition?

Enterprise adds features such as InfoPath Forms Services, advanced search and BI capabilities (varying by version). Both share the same platform.

#Architecture & administration

Q8What is MinRole?

SharePoint 2016+ server roles (Front-end, Application, Distributed Cache, Search, Custom, shared roles) that start only the required services and check compliance.

Q9Why should Distributed Cache have 1 or 3+ hosts, never 2?

The cache cluster relies on quorum, so two hosts don't provide reliable HA. Use one (small farms) or three or more.

Q10Name important service applications.

Search, Managed Metadata, User Profile, Secure Store, Business Data Connectivity, App Management, Subscription Settings, State Service, Usage and Health, Word Automation, Visio.

Q11What is a service application proxy group?

A set of service application proxies associated with web applications, used to give different web applications different services.

Q12How do you troubleshoot "Sorry, something went wrong"?

Take the correlation ID and run Merge-SPLogFile -Correlation <id> across servers, then analyse ULS exceptions. Increase logging temporarily if needed.

Q13What are the six search components?

Crawl, content processing, analytics processing, index, query processing and search administration.

Q14Crawled vs managed properties?

Crawled properties are raw metadata found during crawl. Managed properties are schema entries used in queries and results (searchable, queryable, retrievable, refinable, sortable). Mapping changes need a re-crawl.

Q15Why does the list view threshold exist?

To avoid SQL lock escalation: queries scanning more than about 5,000 rows can lock the shared AllUserData table. Use indexes and filtered views.

Q16Kerberos vs NTLM?

Kerberos is ticket-based, faster, and supports delegation (double hop) to back ends such as SQL and SSRS. NTLM cannot delegate.

Q17What does i:0#.w|contoso\jane mean?

A claims-encoded Windows identity: i identity claim, 0# logon name, .w Windows provider.

#Development

Q18SPSite/SPWeb disposal rules?

Dispose objects you create (new SPSite, OpenWeb, items from AllWebs). Don't dispose objects from SPContext.Current.

Q19Update() vs SystemUpdate()?

Update() creates a version, sets Modified/Editor and fires events. SystemUpdate(false) saves without a new version and keeps Modified/Editor.

Q20Why create a new SPSite inside RunWithElevatedPrivileges?

Elevation applies to objects created inside the delegate. Objects created outside keep the original user's token.

Q21Synchronous vs asynchronous event receivers?

-ing events run before commit and can cancel or modify AfterProperties. -ed events run after commit (usually asynchronously) and cannot cancel.

Q22How do you prevent event receiver recursion?

Set EventFiringEnabled = false before updating in the receiver and restore it in finally.

Q23Why is ListItem null in ItemAdding?

The item doesn't exist yet. Use AfterProperties.

Q24What are feature scopes?

Farm, WebApplication, Site (site collection) and Web.

Q25Add-SPSolution vs Install-SPSolution?

Add uploads the WSP to the solution store. Install deploys it to servers (GAC, hive, web.config) via a timer job.

Q26What is a timer job lock type?

Job (one server), ContentDatabase (once per content DB), None (every server).

Q27CSOM ExecuteQuery?

CSOM batches operations locally and sends them in one request when ExecuteQuery is called.

Q28Why is X-RequestDigest needed in REST?

It is anti-CSRF protection for cookie-authenticated POSTs. It isn't needed with OAuth bearer tokens.

Q29Provider-hosted vs SharePoint-hosted add-ins?

SharePoint-hosted add-ins contain only client-side code in an isolated app web. Provider-hosted add-ins run server code on your own host and call SharePoint with OAuth tokens (ACS or S2S).

Q30Low-trust vs high-trust add-ins?

Low-trust uses Azure ACS tokens (SPO, retired 2026). High-trust uses certificate-signed S2S tokens on-premises.

Q31What are remote event receivers?

Event handlers hosted as WCF services, called by SharePoint via SOAP (ProcessEvent for sync, ProcessOneWayEvent for async), typically registered on AppInstalled.

#Upgrade & lifecycle

Q32Why database attach instead of in-place upgrade?

It is safer and testable: build a new farm, attach and upgrade databases one by one, and keep the old farm as rollback.

Q33Supported path 2013 → SE?

2013 → 2016 → SE via database attach, or a migration tool.

Q34What does Test-SPContentDatabase report?

Missing features, web parts, assemblies, setup files and orphans, plus whether issues are upgrade-blocking.

Q35What is zero-downtime patching?

With redundant MinRole servers, patch half the servers while the others serve traffic, then run PSConfig server by server, with content DBs in backwards-compatibility mode.

Q36What changed in Subscription Edition?

Continuous feature updates, OIDC authentication, TLS 1.3, certificate management in Central Admin, and the PowerShell module.

Q37Which on-prem versions are supported after July 2026?

Only Subscription Edition. 2016 and 2019 reached end of support on 14 July 2026.

Q38What is hybrid's first workload usually?

Hybrid OneDrive (redirect My Sites to OneDrive), followed by cloud hybrid search.

Q39How do you restore a single document after the recycle bin is emptied?

Restore the content DB backup under a new name, connect it as an unattached content database, export with Export-SPWeb -UnattachedContentDatabase and import.

Q40What is the Workflow Manager client?

Assemblies installed on every SharePoint server so SharePoint can communicate with Workflow Manager (2013 platform).
