Nintex Interview Questions

Nintex Workflow and Forms on-premises, Nintex for Office 365, Nintex Automation Cloud (start events, tasks, branch by stage, connections, Xtensions, component workflows), DocGen and migration to NAC.

Deep dives: Nintex tab.

#Platform

Q1What is Nintex Automation Cloud?

Nintex's SaaS automation platform (formerly Nintex Workflow Cloud) with workflows, forms, connectors, DocGen, e-sign and Xtensions, independent of SharePoint.

Q2Nintex for Office 365 vs NAC?

O365 is list-bound via the SharePoint app model and runs in Nintex's cloud. NAC is independent, with connectors and richer features.

Q3What did Nintex acquire around 2019–2020?

Promapp (Process Manager), EnableSoft (RPA) and K2.

#Nintex for SharePoint (on-prem)

Q4What is LazyApproval?

Approving or rejecting by replying to the task email with keywords.

Q5What are workflow constants?

Reusable values and credentials at farm, web app, site collection or site scope.

Q6What are UDAs?

User Defined Actions: reusable parameterized sub-workflows.

Q7Request approval vs Flexi task?

Request approval offers approve/reject. Flexi task has custom outcomes and branching.

Q8Why use a state machine?

For processes with loops and rework where each state sets the next.

Q9How do you call REST from Nintex on-prem?

The Web request action with headers, body and constant credentials, then Query JSON/XML on the response.

Q10How do you keep a Nintex farm healthy?

Purge history and progress data with NWAdmin, avoid pauses in loops, and monitor timer jobs.

Q11How do you find all Nintex workflows?

NWAdmin.exe -o FindWorkflows with a scope (web application or farm).

#Nintex Forms

Q12Formatting vs validation rules?

Formatting rules hide or disable when the condition is true. Validation rules mark the control invalid with a message.

Q13Where is repeating section data stored?

As XML in a connected multi-line text column, parsed with Query XML.

Q14How do you access controls in JavaScript (classic)?

Set a Client ID JavaScript variable name and use NWF$('#' + varName) inside RegisterAfterReady.

Q15How do you extend NAC forms with custom UI?

Custom plugins as web components with getMetaConfig() and ntx-value-change events.

#Nintex Automation Cloud

Q16NAC start events?

Nintex form, SharePoint events, schedule, component workflow, external systems and public forms.

Q17Express approval vs Assign a task?

Express: quick approve/reject by email. Assign a task: custom outcomes, a form, multiple assignees and escalation.

Q18State machine in NAC?

Branch by stage with Go to stage actions.

Q19What is a connection?

Stored authentication for a connector, with usage permissions.

Q20What is an Xtension?

A custom connector from an OpenAPI 2.0 definition, exposing your API as actions.

Q21Component workflows?

Reusable workflows with inputs and outputs called by other workflows.

Q22How does NAC reach on-prem systems?

Nintex Gateway (outbound agent).

Q23DocGen repeating tables?

Bind a table row to a collection variable.

#Migration

Q24Biggest difference migrating O365 → NAC?

List-bound context becomes connector-based, with explicit item context, connections and redesigned forms.

Q25How do you handle in-flight instances?

Freeze starts, let short ones finish, persist state for long ones, and start NAC at the matching stage.

Q26What do you inventory?

Workflows, triggers, actions, forms, runs, owners, dependencies and criticality.

Q27Common unsupported items?

On-prem-only actions (SQL, LDAP), JavaScript in forms, repeating-section XML, and workflow constants.

Q28Nintex vs Power Automate?

Nintex: integrated forms, DocGen, process mapping and process-owner UX. Power Automate: native M365 and Power Platform with seeded licences and enterprise ALM.

Q29Do Nintex on-prem workflows run in SPO after content migration?

No. They must be rebuilt in NAC or another platform.
