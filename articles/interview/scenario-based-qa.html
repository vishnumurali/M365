Scenario-Based Interview Questions

Practical scenarios interviewers love, covering slow lists, failing flows, permission leaks, migration blockers, add-in retirement, Copilot oversharing, approval escalations, InfoPath replacement, SPFx failures and production incidents, with structured answers.

Answer scenarios with structure: clarify → diagnose → options → recommendation → prevention.

#Performance & data

Q1A list with 80,000 items shows threshold errors in a view. What do you do?

Identify the filter and sort columns, index them (script it if the UI blocks), make the first filter indexed and selective, use folders or metadata navigation if needed, and archive closed items. For code, page with RowLimit and indexed OData filters.

Q2A canvas app on SharePoint returns incomplete search results.

Delegation. Search isn't delegable, so only the first 500–2,000 rows are searched. Use StartsWith on indexed columns, server-side search via a flow, or move to Dataverse.

Q3Users say the intranet home page is slow.

Measure with Page Diagnostics and the dev dashboard. Look for heavy SPFx bundles, too many web parts and roll-ups, large images, Embed iframes and unoptimized Highlighted content scopes. Fix with lazy loading, fewer web parts, image optimization and caching.

#Automation

Q4An approval flow sends duplicate emails.

Probably a "created or modified" trigger re-firing on the flow's own update, or concurrent runs. Add trigger conditions (status, editor), set concurrency control, and make the flow idempotent.

Q5A critical flow stopped running over the weekend.

Check run history and the connection (expired password or licence of the owner?), whether the flow is turned off (owner left?), and throttling. Fix by moving to a solution with a service-account connection reference, co-owners and failure alerts.

Q6Business wants approvals that can wait 60 days.

Flows max out at 30 days. Persist status on the item, use timeouts with escalation, and split into restartable flows (or a state machine pattern).

#Security & governance

Q7An employee found salary files through Copilot.

Copilot exposed existing oversharing. Immediately restrict the site (remove broad groups, restricted access control or content discovery), investigate sharing links, run data access governance reports tenant-wide, apply sensitivity labels, and run owner access reviews.

Q8A partner should see only one library on a project site.

Prefer a separate site or library with unique permissions for the partner group. Enable guest sharing only on that site with expiration, and use specific-people links.

Q9Audit asks who changed a deviation's severity last year.

Dataverse auditing (if enabled at environment, table and column level) or SharePoint version history. If not available, explain the gap and enable auditing with retention now.

#Migration & modernization

Q10Add-ins stopped working in April 2026. What now?

ACS and add-ins were retired. Inventory with the M365 Assessment tool, rebuild UI in SPFx, move server logic to Azure Functions with Entra app plus certificate and Sites.Selected, and replace RERs with webhooks.

Q11ShareGate reports thousands of "user not found" warnings.

Departed or unsynced users. Build a user mapping file (placeholder account for leavers), verify Entra Connect sync, and rerun incrementally.

Q12After migration, managed metadata columns are empty.

The term store wasn't migrated with matching IDs. Migrate terms with GUIDs first, then rerun content with property mapping.

Q13A 2-million-file library must move quickly.

Split by year or business unit, ROT clean-up, Insane mode or Migration API, parallel jobs, off-peak runs and incremental passes, with a final freeze.

Q1460 InfoPath forms must be replaced in 6 months.

Inventory and classify. Retire unused forms. Simple list forms go to form formatting or Power Apps list forms. Complex form libraries are redesigned with child lists and flows. Prioritize by usage and criticality, and migrate in waves with templates and reusable components.

#SPFx & integration

Q15An SPFx web part works for admins but not users.

Permissions. API access approved? User rights on lists? Dataverse security role? Test with persona accounts and check 403s in the network tab.

Q16An SPFx web part must call SQL with secrets.

Never from the browser. Add an Entra-protected Azure Function with managed identity to SQL, called via AadHttpClient.

Q17Users see "web part not found" after deployment.

The component ID changed or the solution was retracted. Restore the ID and redeploy.

Q18Webhook processing randomly misses changes.

Subscription expired (no renewal), token not stored or not advanced correctly, or receiver timeouts. Add a renewal job, GetChanges with a persisted token, queue-based processing and idempotency.

#Delivery

Q19A stakeholder wants a "quick Power App" for 5,000 users with premium data.

Clarify licensing (premium per user), data volume and security, then propose options: Dataverse with licences, SharePoint plus standard connectors with limits, or SPFx for broad read-only audiences. Document the decision in the HLD.

Q20Your sprint demo failed because of environment differences.

No environment variables or connection references, or dev-only data. Adopt solutions, environment variables, managed deployments to test and seeded test data.

Q21The client wants everything migrated "as-is" including 15 years of files.

Present ROT analysis (cost, risk, Copilot noise), propose archive tiers and retention, migrate active content, and archive the rest read-only.

Q22Production incident: SharePoint site returns 403 for a department.

Check recent permission changes (audit log), sensitivity label changes, restricted access control, group membership sync, and conditional access. Restore access via the group and communicate.

Q23A Nintex O365 workflow must move to NAC in 2 weeks.

Inventory actions and forms, use the migration tool for conversion, rebuild unsupported parts (forms, scripts), set connections with a service account, test with real roles and cut over with in-flight handling.

Q24How do you decide between Power Automate and Azure Functions?

Power Automate for maker-owned, M365-centric, moderate-volume automation. Functions for high-volume, complex logic, custom protocols, strict performance or pro-dev ALM, or a hybrid of both.
