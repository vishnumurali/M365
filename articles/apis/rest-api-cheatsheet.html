#Headers

Header Value
Accept application/json;odata=nometadata (or verbose / minimalmetadata)
Content-Type application/json;odata=nometadata
X-RequestDigest From POST /_api/contextinfo (cookie auth only)
IF-MATCH * or ETag (update/delete)
X-HTTP-Method MERGE (update), DELETE (with POST)
Authorization Bearer <token> (apps)

#OData query options

Option Example
$select $select=Id,Title,Author/Title
$expand $expand=Author,Lookup
$filter Status eq 'Open' and Amount gt 100 · startswith(Title,'DEV') · substringof('pump',Title) · Created ge datetime'2026-01-01T00:00:00Z'
$orderby Created desc
$top $top=5000 (max)
Paging Follow odata.nextLink ($skiptoken=Paged=TRUE&p_ID=…)
Pro tip

RenderListDataAsStream This endpoint returns list data as views render it, including formatted values of every field type, managed metadata labels and person details. It is great for exports and complex fields.

#Interview questions

Q1How do you update a list item with REST?

POST to /_api/web/lists/getbytitle('X')/items(id) with headers X-HTTP-Method: MERGE, IF-MATCH: * (or an ETag), the digest (for cookie auth) and a JSON body containing only the changed fields. Success returns 204.

Q2How do you copy a file across site collections with REST?

Use SP.MoveCopyUtil.CopyFileByPath (or CopyFolderByPath), or the Graph copy action on a driveItem, both of which support cross-site copies. copyTo on a file only works within the same site.
