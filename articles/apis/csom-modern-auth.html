CSOM for .NET with Modern Authentication (MSAL) – After SharePointOnlineCredentials and ACS

Use CSOM with Microsoft.SharePointOnline.CSOM on .NET 6/8, acquiring tokens with MSAL (interactive, certificate app-only, managed identity), the ExecutingWebRequest pattern, PnP Framework AuthenticationManager, and migrating old code that used SharePointOnlineCredentials or ACS.

Old CSOM samples used SharePointOnlineCredentials (username/password, legacy auth) or ACS app-only. Both are blocked or retired. Modern CSOM uses access tokens from Entra ID.

App-only CSOM with a certificate (MSAL)C#
using Microsoft.Identity.Client;
using Microsoft.SharePoint.Client;
using System.Security.Cryptography.X509Certificates;

var cert = new X509Certificate2("deviation-sync.pfx", Environment.GetEnvironmentVariable("PFX_PASSWORD"));
var msal = ConfidentialClientApplicationBuilder.Create(clientId)
    .WithCertificate(cert).WithTenantId(tenantId).Build();

async Task<string> GetTokenAsync() =>
    (await msal.AcquireTokenForClient(new[] { "https://contoso.sharepoint.com/.default" }).ExecuteAsync()).AccessToken;

using var ctx = new ClientContext("https://contoso.sharepoint.com/sites/quality");
// The event is synchronous: resolve the (MSAL-cached) token synchronously, never with an async void lambda
ctx.ExecutingWebRequest += (s, e) =>
    e.WebRequestExecutor.RequestHeaders["Authorization"] = "Bearer " + GetTokenAsync().GetAwaiter().GetResult();

var list = ctx.Web.Lists.GetByTitle("Deviations");
ctx.Load(list, l => l.ItemCount);
await ctx.ExecuteQueryAsync();
Console.WriteLine(list.ItemCount);
Shortcut: PnP Framework AuthenticationManagerC#
var am = new PnP.Framework.AuthenticationManager(clientId, "deviation-sync.pfx", pfxPassword, "contoso.onmicrosoft.com");
using var ctx = await am.GetContextAsync("https://contoso.sharepoint.com/sites/quality");
App-only = certificate

SharePoint app-only CSOM/REST requires certificate-based tokens (or managed identity), and the app needs SharePoint permissions (Sites.Selected + site grant, or Sites.FullControl.All).

ACS app-only (TokenHelper.GetAppOnlyAccessToken) Entra app + certificate (MSAL / PnP Framework)

#Interview questions

Q1How do you authenticate CSOM on .NET 8 against SharePoint Online?

Acquire an access token for https://<tenant>.sharepoint.com/.default with MSAL or Azure.Identity (interactive, certificate-based app-only or managed identity), and add it as a Bearer header in the ClientContext.ExecutingWebRequest event. Alternatively, use PnP Framework's AuthenticationManager.

Q2Why does old code using SharePointOnlineCredentials fail?

It relies on legacy username/password authentication (WS-Trust/IDCRL), which conflicts with MFA and Conditional Access and is blocked or disabled in most tenants. CSOM for .NET Standard doesn't support it.
